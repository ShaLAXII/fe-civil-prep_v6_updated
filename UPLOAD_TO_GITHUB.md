# FE Civil Prep - Learnova Only

This package removes the M. R. Islam book and all 802 corresponding question records.
It retains 1,052 Learnova main-book questions plus 440 positions from four Learnova practice exams (1,492 indexed positions total; some may overlap).

## Upload

1. Unzip this package. Do not upload the ZIP itself.
2. Upload the extracted files into your existing GitHub repository, replacing files with the same names.
3. **Delete the old `islam.pdf` file from the repository**, if it exists. The new ZIP cannot delete old GitHub files on its own.
4. Commit your changes. Keep `index.html` at the repository root.
5. Refresh the GitHub Pages website after deployment.

Custom practice, timed exams, diagrams and original source-page viewer remain available. Existing saved Learnova progress uses the same browser key. In-progress sessions with removed questions are dropped.

Answers and reconstructed question text have not all been independently checked. Some entries are ungraded for safety, though all remain available to browse.

Only publish PDF content if you hold permission for public redistribution.
